# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 1.x | yes |
| < 1.0 | no |

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately through
[GitHub Security Advisories](https://github.com/bekirhankarakurt/reliable-udp-transfer/security/advisories/new)
("Report a vulnerability" on the repository's Security tab).

Include the affected version, a description of the impact and, if possible, a reproducer
(for example a crafted input file or packet). You can expect an acknowledgement
within a few days and a fix or mitigation plan once the report is confirmed.
